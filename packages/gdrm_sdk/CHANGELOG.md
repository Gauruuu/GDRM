## 1.0.0

* Initial release of GDRM Enterprise SDK (`gdrm_sdk`).
* Added `GdrmEngine` for hardware-locked `.gdrm` file packing, parsing, and in-memory decryption.
* Added `GdrmSecureViewer` turnkey widget for Flutter applications with automatic `.pdf` vs `.gdrm` detection.
* Added `GdrmDynamicWatermark` with dynamic forensic watermarking and AI-deterrence directives.
* Added support for time-bombs (`riggedExpiry`), chrono-embargoes (`openAt`), password verification, and tamper meltdown protection.
